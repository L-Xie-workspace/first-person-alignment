# A First-Person Necessary Condition for Alignment in AI Systems with AGI-like Properties

This repository contains a conceptual research note exploring alignment
from a first-person experiential perspective.

The paper proposes a possible necessary condition for alignment in
systems with AGI-like properties, focusing on long-term experiential
stability rather than purely external behavioral constraints.

This is an evolving document and may be updated over time.
